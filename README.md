# AI Comment Analyzer

An AI-powered sentiment analysis dashboard built using Streamlit and Hugging Face Transformers.

## Features

- Add comments
- Sentiment classification
- Edit/Delete comments
- Search comments
- Sentiment analytics
- CSV Export
- PDF Report Generation

## Technologies Used

- Python
- Streamlit
- Transformers
- Plotly
- Pandas
- FPDF

## Run Locally

```bash
pip install -r requirements.txt
streamlit run main.py
